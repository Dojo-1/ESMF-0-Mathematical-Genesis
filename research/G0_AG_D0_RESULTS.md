## Verdict and exact evidence class

**M — measured, but only for the specified synthetic conditional mechanism.** The placebo matched full exactly for every paired seed, all event-destination state sets matched, and all resource ledgers closed. In **24 paired development replicates**, each 0.75 arbitrary time units, no clear beneficial developmental effect emerged from the extra geometry-to-growth or glial rate modifiers. There were **zero paid quaternionic connection repairs in every arm**. No predictive competence, contextual generalization, viable biological growth or cognition was measured.

This is negative/inconclusive engineering triage, **not** evidence that a richer algebra is necessary. Original G0-AG1 heldout protocol remains unrun.

## Intentionally conditioned starting state

A deterministic sequence of legitimate positive-rate events made both mechanisms active: paid neurite extension, neuron-neuron contact, glial calcium and tripartite binding, contextual encounter, ATP-paid phase revision, nutrient and material resupply. The starting state contained a contact, tripartite support and quaternionic endpoint discrepancy **0.12031849747679974**. All arms shared initial state, observations, capacity, potential transition destinations and resource budgets.

This is a heavily **selected challenge**, not a natural developmental history. It measures the behavior of mechanisms after activation, not their probability of arising endogenously.

The unchanged placebo equals the full arm **on all recorded fields for all 24 paired seeds**. Every sampled state remained within the synthetic viability envelope, with zero material and combined-energy residual.

The paired full-minus-no-geometry difference in physical extension count was **0** for these particular 24 seeds (descriptive interval [0,0]); this does *not* establish a zero population effect. The paired full-minus-no-glial-rate difference was **+0.04167** extensions per run, descriptive normal-approximation 95% interval **[-0.0400, +0.1233]**. Contact and tripartite exposure comparisons had small differences and corresponding intervals crossing zero.

The central obstruction is now measurable: **connection repair never happened at this horizon**. The causal influence of a rich structural layer cannot be inferred when the layer remains largely unused.

## Parity and independent evidence limitations

- Identical initial state, observation setting, state capacity and event-destination graph: **verified**.
- Same random seed per arm: **verified**; rate changes still produce different stochastic histories, so event-level common randomness is not guaranteed.
- Same *realized* external nutrient or material spending: **not achieved**; the table explicitly exposes differences between runs.
- Equal computational costs between genuinely different models: **not tested**; all arms retain the same code and differ in rates only.
- Fully independent verification: **absent**. GitHub CI independently executes author-defined tests; it does not provide independent task truth.
- Predictive/action return, semantic correctness, context-boundary discovery, false budding and biological meaning: **not measured**.
- Confidence intervals are **descriptive normal approximations** for n=24, not confirmatory or preregistered significance tests.

CPU time for all 120 synthetic trajectories was approximately **2.482 seconds** on a GitHub runner. This is not a fair hardware-efficiency or energy measurement.

## Decision and evidence map

**Do not add another algebraic lift to explain away the result.** A correct next test needs a held-out *decision* with independent truth conditions, equal realized resource-spending comparisons, calibrated coverage and a competitive conventional context-aware estimator. Judge whether growth improves later action or prediction more than using the same storage/memory without physical growth.

**P:** conditional CTMC event-rate and bookkeeping identities. **M:** the bounded D0 trajectory observations and exact null. **H:** cognitive or biologically useful benefit of continuous quaternion transport, glia and rank growth. **A:** synthetic Mat2(R)-to-quaternion observation adapters and resource-to-biology analogies. **R:** any interpretation that architectural complexity alone validates meaningful ESMF-0 learning.
